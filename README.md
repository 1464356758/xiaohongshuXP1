# XHS-XP1｜小红书美妆AI多角色人工工作流

这是一个与 `xiaohongshu2` 使用方式相同的普通聊天多角色工作流，但底层使用新版16角色架构。

## 你怎么用
1. 打开 `角色/00_角色建立与初始化说明.md`
2. 在GPT新项目里一次性建立16个独立角色聊天
3. 每个聊天粘贴对应 `角色/01-16` 文件
4. 从【R01 运营总监AI】开始
5. 之后只复制每个角色最后的正式交接给指定角色
6. 一路做到选题、商品/SKU、文案、视觉、图片、三审、合规、CONTENT LOCK、发布包
7. 真实发布由用户本人完成

## 入口
- `启动说明.md`
- `角色工作流.md`
- `数据库入口.json`
- `当前进度.json`

## 当前状态
首次启动，等待R01执行ROUTER_BOOTSTRAP。
生产状态为 `READY / INTAKE`。

## 原则
GitHub是唯一正式真源。
角色之间不依赖旧聊天记忆传正式状态。
具体商品必须先锁PRODUCT/SKU。
图片必须经过资产身份与独立三审。
没有CONTENT LOCK与发布许可不得发布。
